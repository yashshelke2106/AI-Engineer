# Exact pins, deliberately.
#
# This project writes a pickled estimator to disk (autoeng/registry/) and
# records the versions it was fit under in training_schema.json, warning on
# mismatch at load. Range constraints make that warning meaningless: two
# machines both satisfying `numpy>=1.26` can install 1.26 and 2.2, and every
# artifact one produces warns against the other for no real reason. A warning
# that fires constantly is a warning nobody reads.
#
# It is not hypothetical. During development `pip install mlflow` silently
# lifted numpy from 1.26.4 to 2.2.6 mid-session; both satisfied the old
# `numpy>=1.26` line.
#
# These are the versions the 91-test suite passes on. To move one, change it
# here, run `pytest tests/ -q` and `python scripts/calibrate_detection.py`
# (10/10 is the bar), and commit the pin with the result.
